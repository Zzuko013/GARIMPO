# GARIMPO — Curadoria Independente de Moda

Aplicação web de curadoria de moda masculina e unissex, análise de tecidos/gramaturas e comparador de preços em tempo real.

## 🚀 Como Executar Localmente (VS Code / Terminal)

Este projeto utiliza **Node.js** padrão com **Vite**, **React 19**, **TypeScript** e **Tailwind CSS v4** (não depende obrigatoriamente do Bun, funcionando 100% com `npm`, `pnpm`, `yarn` ou `bun`).

### 1. Instalar as dependências
```bash
npm install
```

### 2. Rodar o servidor de desenvolvimento
```bash
npm run dev
```

Abra no navegador em `http://localhost:3000`.

### 3. Build de Produção
```bash
npm run build
```

---

## 🛠️ Tecnologias
- **React 19** + **TypeScript**
- **Vite 6** com `@vitejs/plugin-react`
- **Tailwind CSS v4** com `@tailwindcss/vite`
- **Lucide React** (ícones vetoriais)
- **Motion** (animações de transição)
- Suporte a imagens com fallback automático contra bloqueios de CDN ou conexões instáveis.
